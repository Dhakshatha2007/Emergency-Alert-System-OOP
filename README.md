# Universal Smart Emergency Alert System (OOP - Java)

## 📌 Description
This project is a console-based emergency alert system developed using Object-Oriented Programming in Java. It allows users to select different types of emergencies and generates appropriate alert messages.

## 🚀 Features
- Supports multiple emergency types
- Generates different alert responses
- Simple and user-friendly interface
- Demonstrates OOP concepts

## 🧠 OOP Concepts Used
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

## ⚙️ How It Works
1. User enters name and location
2. Selects emergency type
3. System creates corresponding object
4. Alert message is displayed
